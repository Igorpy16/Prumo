      Prumo

      Controle financeiro pessoal. Seus lançamentos ficam em um banco SQLite no seu servidor; nada é enviado a terceiros. Só os indicadores de mercado vêm de uma API pública.

      Créditos

      • Indicadores: Banco Central do Brasil, Dados Abertos (SGS), licença ODbL. Projeto não afiliado ao BCB.
      • Fontes: Bricolage Grotesque e Figtree (SIL OFL), via Fontsource.
      • Feito com FastAPI, SQLite e JavaScript puro.
